# Skill optimization

Improve agent skills from realistic use: observe a failure, diagnose its cause, make a small correction, and retest with a fresh context. Keep meaningful review while reducing unnecessary execution cost.

Install this folder as a skill using your host's supported discovery mechanism. No scripts, external service, or additional runtime is required; executing trials uses the target skill's own dependencies and permissions.

Try: “Use skill-optimization to improve this handout skill. Run an isolated task from raw inputs, preserve the baseline, and return a reviewed candidate without publishing.”

See the [agent workflow](SKILL.md) and [original worked example](references/worked-example.md). Results apply to the tested scope; structural checks do not prove semantic or visual quality. Licensed under [MIT](LICENSE).
