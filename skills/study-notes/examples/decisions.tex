\ParallelParagraph{goal-b}{\StudyGraphChoice{2}{Retrieve known material from a remembered term or task.}{choose-lookup}}{\StudyGraphChoice{2}{根据记得的词语或任务检索已知内容。}{choose-lookup}}

\StudyGraphNode{choose-lookup}
\ParallelParagraph{lookup-prerequisite}
 {Establish what the reader expects after finding the term. A compact answer includes the rule and its conditions; a location identifies where the explanation is found. Ask which is needed if the request does not say.}
 {先明确读者找到词语后期待什么。简明答案包含规则及适用条件；定位信息说明在哪里能找到解释。要求中没有说明时，就先询问。}
\ParallelParagraph{lookup-a}{\StudyGraphChoice{1}{A usable explanation or rule is needed at the lookup point.}{make-quick}}{\StudyGraphChoice{1}{需要在查找处直接获得可用的解释或规则。}{make-quick}}
\ParallelParagraph{lookup-b}{\StudyGraphChoice{2}{Only locations in an included document are needed.}{make-index}}{\StudyGraphChoice{2}{只需要随附文档中的位置。}{make-index}}
\StudyGraphNode{make-notes}
\ParallelParagraph{notes-method}
 {Explain the concept's meaning and assumptions, then show why its mechanism produces the result. Work through one application with inputs, intermediate reasoning and a checked answer. This supports understanding rather than merely recognizing a name. Map each claim to the source or label it as derived explanation. Use the common paragraph-flow setting for long prose.}
 {解释概念的含义与假设，再说明其机制为何产生相应结果。通过一个应用实例展示输入、中间推理和经过核对的答案。这样能帮助理解，而不只是记住名称。将每项论断对应到来源，或标明它是推导解释。长正文使用公共段落跨页设置。}
\StudyGraphNode{make-quick}
\ParallelParagraph{quick-method}
 {Write each compact answer once as a canonical entry, including the conditions that make it valid. Add remembered terms and task keywords as direct routes to that entry or its precise subentry. Sort substantive entries and routes together so the reader searches one place. Try realistic remembered-word queries and verify each generated target page; preserve distinct meanings with context labels.}
 {将每个简明答案写成唯一的规范条目，并包含其成立的条件。把记忆词和任务关键词设置为直接指向该条目或准确子条目的路径。将实质内容与路径一起排序，让读者只需在一个位置检索。用真实的记忆词测试，并核对自动生成的目标页码；通过上下文标签保留不同含义。}
\StudyGraphNode{make-index}
\ParallelParagraph{index-method}
 {Use the same canonical registry as the Quick Reference, rendering only terms and exact locations. Keep substantive explanations in the included target document, and name the document, section and generated page so the pointer also works in print. Test the links and check that every target is delivered. This compact view is appropriate only when the reader needs locations rather than an answer at the lookup point.}
 {使用与速查相同的规范记录，仅显示词语与准确位置。把实质解释保留在随附的目标文档中，并注明文档、章节及自动页码，让纸质定位也能使用。测试链接，并检查每个目标文档都已交付。只有读者需要位置、而不需要在查找处直接获得答案时，这种紧凑视图才合适。}
\StudyGraphNode{make-tree}
\ParallelParagraph{tree-method}
 {Identify the observable conditions that change the solution. Put prerequisite inspections beside each natural question and order A/B/C conditions by first-match priority. At each solution, explain the applicable reasoning, executable steps and a result check. Resolve missing facts inline where possible; a separate branch is useful when gathering them is a substantive task. For a genuine loop, state the changing information and exit condition. Exercise realistic paths and inspect every final page before delivering the selected form with its native source and source map.}
 {找出会改变解法的可观察条件。在每个自然问题旁写明前提检查，并按首次匹配优先顺序排列 A/B/C 条件。在每个解法中说明适用的推理、可执行步骤和结果检查。尽可能就地补齐缺失信息；只有收集信息本身是一项实质任务时，才使用独立分支。真正需要循环时，说明变化的信息与退出条件。走通真实路径，检查全部最终页面，再将所选资料、原生源文件与来源映射一起交付。}
