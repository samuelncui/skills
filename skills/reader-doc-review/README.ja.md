# 読者に基づく文書レビュー

実際の読者のために一つの文書をレビューし、改訂します。まず事実を集めます。読者は誰か、読んだ後に何をするか、文書の目的と範囲、著者の意図です。次に、新しいコンテキストの読者に実際のタスク質問へ答えてもらい、指摘を分類して文書を直し、修正ごとに確認します。新しい問題が出ない回まで繰り返します。提案書、設計書、ガイド、README、規程、マニュアルなど、テーマ・形式・入手元を問いません。

利用環境が対応するスキル検出の仕組みで、このフォルダーをインストールしてください。二つの任意の補助スクリプトには Python 3 が必要です。`scripts/sweep.py` は編集前に同じ事実の記述をすべて列挙し、`scripts/textdiff.py` は文書の二つの書き出しを比較します。文書の読み書きには既存のアクセス手段を使います。このスキルは公開権限を与えません。

依頼例：「reader-doc-review でこの設計提案をレビューしてください。読者は承認するマネージャーと実装するエンジニアです。まず事実を私と確認し、新しい問題が出なくなるまでレビューと修正を繰り返し、私が決めるべき事項を一覧にしてください。」

英語の[エージェント向け手順](SKILL.md)、[テンプレート](references/templates.md)、[オリジナルの実例](references/worked-example.md)を参照してください。読者による試読は、試した読者が文書を使えるかを示すもので、設計の正しさを証明するものではありません。[MIT ライセンス](LICENSE)で提供します。
