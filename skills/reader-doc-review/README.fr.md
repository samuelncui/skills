# Relecture de documents centrée sur les lecteurs

Relisez et révisez un document pour les personnes qui le liront vraiment. Rassemblez d’abord les faits : qui lit, ce que chaque lecteur doit faire ensuite, l’objectif et le périmètre du document, l’intention de l’auteur. Donnez ensuite à des lecteurs en contexte neuf de vraies questions de tâche, triez leurs retours, corrigez le document et vérifiez chaque modification. Recommencez jusqu’à ce qu’un tour ne révèle rien de nouveau. Convient à tout sujet, format ou source : propositions, conceptions, guides, README, politiques et manuels.

Installez ce dossier avec le mécanisme de découverte des compétences de votre environnement. Les deux aides facultatives nécessitent Python 3 : `scripts/sweep.py` liste chaque énoncé d’un fait avant de le modifier, et `scripts/textdiff.py` compare deux exports du document. La lecture et l’écriture du document passent par l’accès dont vous disposez déjà ; cette compétence n’accorde aucun droit de publication.

Exemple : « Utilise reader-doc-review sur cette proposition de conception. Les lecteurs sont la responsable qui valide et les ingénieurs qui la réaliseront. Confirme d’abord les faits avec moi, puis enchaîne relectures et corrections jusqu’à ce que rien de nouveau n’apparaisse, et liste les décisions qu’il me reste à prendre. »

Consultez la [procédure pour l’agent](SKILL.md), les [modèles](references/templates.md) et l’[exemple original détaillé](references/worked-example.md), en anglais. Les essais de lecture montrent si les lecteurs testés peuvent utiliser le document ; ils ne prouvent pas que la conception est juste. Licence [MIT](LICENSE).
