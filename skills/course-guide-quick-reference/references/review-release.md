# Review and delivery

Match review depth to the requested scope. An outline or small sample needs a focused check; a course-wide production deliverable needs complete coverage and whole-set review. If a staged draft is useful, label its remaining gaps precisely rather than treating a “Beta” label as a substitute for review.

## Content

Read each section against the actual source map. Check definitions, claims, assumptions, notation, units, derivations, examples, figure meaning, translations and source attribution. A reviewer should read the material itself, not only a script report or a list of headings. Use independent domain/language review where warranted and available; state which parts were author-only review or remain uncertain.

For bilingual work, read each language independently for naturalness, then reconcile corresponding units. Check negation, bounds, numbers, named concepts and caveats carefully. Do not treat matching paragraph counts as semantic equivalence.

## Retrieval

Try realistic questions that start from a keyword or alias. Each should lead to a canonical concept, then a correct notes section/page. Check the exact final PDFs after all pagination changes. Moving the PDFs apart may break relative cross-document links; explain the distribution structure.

## Rendering

Run the mechanical checks, then inspect every rendered page at readable resolution. Check density, text size, same-page pairs, mathematical placement, list direction, figure proportions and labels, tables, clipping, missing glyphs, references and optional cover/blank parity. Automated checks find classes of defects but do not certify an accurate translation or a meaningful diagram.

## Handoff

Deliver the requested notes and Quick Reference, portable editable project, structured input when used, source/coverage map and a brief status statement. Distinguish passed, failed, pending and unrun checks. Do not publish private course sources, identities, access links, file paths or operational logs. Publication and external translation services require the user's applicable authorization.
