Build a paired reading pageCréer une page de lecture bilingue

This original guide demonstrates bilingual-html using its own embedded-pair format. Each English passage stays beside its French counterpart on a wide screen and immediately before it on a narrow screen.Ce guide original présente bilingual-html à l’aide de son propre format de paires intégrées. Sur un écran large, chaque passage anglais reste à côté de sa version française ; sur un écran étroit, il la précède immédiatement.

1. Prepare complete pairs1. Préparer des paires complètes

Start with text whose two language versions are already supplied. Keep the source wording and its matching target together in one pair with a stable identifier. This renderer does not create or approve translations.Commencez par un texte fourni dans les deux langues. Conservez le texte source et sa version cible dans une même paire dotée d’un identifiant stable. Ce moteur ne produit ni ne valide les traductions.

  1. Read the entire input and identify headings, paragraphs, list items, table cells, captions and image descriptions.Lisez l’ensemble du contenu et repérez les titres, les paragraphes, les éléments de liste, les cellules de tableau, les légendes et les descriptions d’image.
  2. Give every structural occurrence its own pair ID. Include both nonempty texts, even when a label repeats elsewhere.Attribuez un identifiant de paire à chaque occurrence structurelle. Fournissez les deux textes non vides, même lorsqu’un libellé est répété ailleurs.
  3. Set each language tag and direction independently. Choose desktop column order only after the source and target roles are clear.Définissez séparément la balise de langue et le sens d’écriture de chaque langue. Choisissez l’ordre des colonnes sur ordinateur après avoir précisé les rôles source et cible.

2. Preserve useful structure2. Conserver une structure utile

A bilingual table keeps one shared row structure. Each header or data cell contains both texts, so related values remain in the same logical cell.Un tableau bilingue conserve une structure de lignes commune. Chaque cellule d’en-tête ou de données contient les deux textes, afin que les valeurs correspondantes restent dans la même cellule logique.

3. Render and inspect3. Générer et vérifier

Run scripts/bilingual_html.py render layout.json --output page with Python 3.11 or later. Choose a new directory whose parent already exists, then open page/index.html in a browser.Exécutez scripts/bilingual_html.py render layout.json --output page avec Python 3.11 ou une version ultérieure. Choisissez un nouveau dossier dont le parent existe déjà, puis ouvrez page/index.html dans un navigateur.

Text is literal: <em> stays visible, an ampersand remains &, and TeX such as \\alpha is not executed. Rich trusted HTML requires a separate, manually reviewed authoring route.Le texte est littéral : <em> reste visible, une esperluette reste &, et du TeX comme \\alpha n’est pas exécuté. Un document HTML enrichi et fiable nécessite un parcours de rédaction distinct, vérifié manuellement.

  • Inspect desktop and mobile widths, table relationships, line wrapping, and the shared image.Vérifiez les largeurs d’écran d’ordinateur et de mobile, les relations du tableau, le retour à la ligne et l’image commune.
  • Read both languages for completeness and meaning. Inspect actual glyphs and shaping when choosing fonts or right-to-left text.Lisez les deux langues pour en vérifier l’exhaustivité et le sens. Examinez les glyphes et leur composition lorsque vous choisissez des polices ou un texte de droite à gauche.
  • Deliver index.html, style.css, LICENSE and the image folder together. The page uses no remote fonts, scripts or images.Livrez ensemble index.html, style.css, LICENSE et le dossier d’images. La page n’utilise aucune police, aucun script et aucune image distants.

4. Import translation work only when needed4. Importer le travail de traduction si nécessaire

Already paired layout JSON renders with bilingual-html alone. For raw source, discover the separately installed bilingual-translation skill. Its reviewed version-1 output can be imported with an explicit skill path; unresolved or stale units stop the import.Un fichier JSON de mise en page contenant déjà les paires se génère avec bilingual-html seul. Pour un texte source brut, recherchez la compétence bilingual-translation installée séparément. Son résultat révisé au format version 1 peut être importé en indiquant explicitement le chemin de la compétence ; les unités incomplètes ou obsolètes bloquent l’importation.

Escaping and structural checks are objective safeguards. They do not certify translation quality, font coverage or accessibility. Record the actual checks and review the delivered page in its intended viewing environment.L’échappement et les contrôles de structure sont des protections objectives. Ils ne certifient ni la qualité de traduction, ni la couverture des polices, ni l’accessibilité. Consignez les contrôles réellement effectués et examinez la page livrée dans son environnement de consultation prévu.
