# 面向读者的文档审阅

针对实际读者审阅并修改一篇文档。先收集事实：读者是谁、读完要做什么、文档的目的、范围和作者意图。然后请全新上下文的读者回答真实任务问题，对反馈分类处理，修改文档并逐次核对修改，循环直到某一轮不再出现新问题。适用于任何主题、格式和来源：方案、设计、指南、README、制度和手册。

使用宿主支持的技能发现方式安装此文件夹。两个可选辅助脚本需要 Python 3：`scripts/sweep.py` 在修改前列出同一事实在全文的所有表述，`scripts/textdiff.py` 比较文档的两次导出。文档的读取和写入使用你已有的访问方式；本技能不授予发布权限。

示例请求：“用 reader-doc-review 审阅这份设计方案。读者是负责审批的经理和负责实现的工程师。先和我确认事实，再循环审阅和修改，直到没有新问题，最后列出还需要我决定的事项。”

参见[agent 工作流程](SKILL.md)、[模板](references/templates.md)和[原创完整示例](references/worked-example.md)（英文）。读者试读只说明被测读者能否用好这份文档，不能证明设计本身正确。采用 [MIT 许可证](LICENSE)。
