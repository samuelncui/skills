# 技能优化

通过真实任务改进 agent 技能：观察问题、分析原因、做小范围修正，再用全新上下文复测。在保留必要审查的同时减少无效执行成本。

使用宿主支持的技能发现方式安装此文件夹。技能本身不需要脚本、外部服务或额外运行时；试验使用目标技能所需的依赖，并遵循已有权限。

示例请求：“使用 skill-optimization 改进这个讲义技能。从原始输入开展隔离试验，保留基线，返回经过审查的候选版本，不要发布。”

参见[agent 工作流程](SKILL.md)和[原创完整示例](references/worked-example.md)（英文）。结论仅覆盖已测试范围；结构检查不能证明语义或视觉质量。采用 [MIT 许可证](LICENSE)。
