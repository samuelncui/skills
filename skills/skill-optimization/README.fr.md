# Amélioration des compétences

Améliorez les compétences d’un agent à partir de tâches réalistes : observer un échec, en rechercher la cause, apporter une petite correction, puis refaire un essai dans un contexte neuf. Conservez les revues utiles tout en réduisant les coûts d’exécution superflus.

Installez ce dossier avec le mécanisme de découverte des compétences de votre environnement. Aucun script, service externe ou environnement d’exécution supplémentaire n’est requis pour cette compétence ; les essais utilisent les dépendances et autorisations de la compétence évaluée.

Exemple : « Utilise skill-optimization pour améliorer cette compétence de création de fiches. Effectue un essai isolé à partir des données brutes, conserve la version de référence et fournis une version candidate revue, sans la publier. »

Consultez la [procédure pour l’agent](SKILL.md) et l’[exemple original détaillé](references/worked-example.md), en anglais. Les résultats se limitent au périmètre testé ; les vérifications structurelles ne prouvent pas la qualité sémantique ou visuelle. Licence [MIT](LICENSE).
