# スキルの改善

実際のタスクを通じてエージェントのスキルを改善します。問題を観察し、原因を調べ、小さく修正してから、新しいコンテキストで再試行します。必要なレビューを維持しながら、不要な実行コストを減らします。

利用環境が対応するスキル検出の仕組みで、このフォルダーをインストールしてください。このスキル自体にはスクリプト、外部サービス、追加の実行環境は不要です。試行では対象スキルの依存関係と許可範囲に従います。

依頼例：「skill-optimization を使って、この配布資料作成スキルを改善してください。元の入力から隔離した試行を行い、基準版を保存し、公開せずにレビュー済みの候補版を返してください。」

英語の[エージェント向け手順](SKILL.md)と[オリジナルの実例](references/worked-example.md)を参照してください。結果はテストした範囲に限られ、構造チェックだけでは意味や見た目の品質を証明できません。[MIT ライセンス](LICENSE)で提供します。
